MÉTODO CALMA - VERSIÓN COMPLETA ANIMADA

1. Descomprimir la carpeta completa.
2. Abrir index.html con Chrome, Edge o Firefox.
3. La página utiliza archivos locales para todas las imágenes.
4. Requiere Internet solamente para Vimeo, Hotmart y Google Fonts.
5. Las animaciones se activan al bajar por la página y respetan la opción del sistema "reducir movimiento".

- index.html
- css/styles.css
- js/main.js
- assets/images/
